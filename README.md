# Cuaderno Santilla React
Cuaderno Santilla React

## Descripcion
Albert me ha pedido que haga esta practica, basicamente es un CRUD de tareas que tenga persistencia

## Funcionalidades
Crear, Editar, Visualizar y Borrar tareas

## Instalacion
1.Clonar el repositorio
git clone https://github.com/PauR07/cuaderno-santillana-react.git

2.Entrar en el proyecto
cd cuaderno-santillana-react

3.Instalar dependencias
npm install

4.Iniciar el servidor de desarrollo
npm run dev
